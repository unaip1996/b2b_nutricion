# Frontend B2B Nutrición

Cliente Next.js para la plataforma B2B Nutrición. Consume la API Symfony indicada por `NEXT_PUBLIC_API_URL`.

## Comandos

```bash
npm ci
npm run dev
npm run check
npm run lint
npm run build
```

La aplicación utiliza App Router. Las rutas viven en `src/app/`, los componentes reutilizables en `src/components/` y las utilidades de acceso a API en `src/lib/`.

La configuración de shadcn/UI se mantiene únicamente en `components.json` en esta carpeta.
